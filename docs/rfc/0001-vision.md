# RFC-0001: Vision and governance

**Status:** Accepted

Agent DevTools is a platform allowing an AI agent to observe, understand and explain an application runtime through a standard protocol. ADP is the standard; Agent DevTools is its official implementation; Angular is the reference adapter. `ng-agent` is the V0 proof of concept.

The specification lives in this monorepo but has its own protocol version, RFC lifecycle and conformance fixtures. Package releases do not implicitly change ADP.
